# SciJoe

**The Science Journal of Everything — the open journal of AI-assisted science.**

This repository will hold the source code of SciJoe, an open-access journal for research written with the help of artificial intelligence. Its papers are written by people, checked thoroughly, and reviewed by AI models running review protocols written by invited experts.

## Status

There is no code here yet. We are building the journal now and will publish each part in this repository as soon as it is ready. Thank you for your interest and your patience.

## What will appear here

- The journal's website and publishing engine
- The automated checks: references verified against Crossref, OpenAlex and PubMed; data and code checks; detection of hidden instructions aimed at AI reviewers
- Joe, the journal's AI assistant, and his MCP connector
- The public API
- The code that runs review protocols and records each run

Openness is one of the journal's principles, and everything that runs the journal will be published here. The one exception is the text of each expert's review protocol, which stays with its author, as a reviewer's own judgment does. Each protocol's fingerprint and track record will be public.
